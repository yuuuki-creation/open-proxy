# 技术债清单

记录已知但暂不处理的问题：临时绕过的方案、简化的实现、缺失的测试、需要重构的代码等。

本文件是规则，属于 main 分支。每个分支一个清单文件：`panel.md`、`agent.md`，只在对应分支上修改（见 [git-workflow.md](../../git-workflow.md)）。

- 新增：追加一行，编号为 `<分支>-<序号>`（例如 `agent-3`），状态填「未处理」
- 处理后：状态改为「已解决」，并注明对应的提交或计划
- 优先级：高（影响正确性或安全）/ 中（影响可维护性）/ 低（影响体验或整洁）

清单文件格式：

````markdown
# <分支> 分支的技术债

| 编号 | 问题 | 位置 | 优先级 | 记录日期 | 状态 |
| --- | --- | --- | --- | --- | --- |
````
