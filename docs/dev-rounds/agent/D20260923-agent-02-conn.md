> 摘要：写了 `agent/internal/conn`：WebSocket 连接、Hello 认证、重连退避、消息 ID 和请求回复、版本不一致时只收发稳定消息、心跳。写的时候发现协议缺口（不认识的消息分不清是请求还是推送），经 main 的 PR #4 改为一律忽略。M2 经 PR #5 合并，CI 全部通过。

## 目的

让 Agent 能连上主控、完成认证，并搭好收发消息的框架，后续阶段只需要在 Handler 里接业务。

## 做了什么

- `agent/internal/conn/client.go`：`Client.Run`（连接、认证、断线重连）、`Client.Send`（发推送）、`Handler` 接口
- `agent/internal/conn/session.go`：一次连接的收消息、分发、请求等待表、心跳
- `agent/internal/conn/messages.go`：哪些消息是稳定消息、哪些是请求
- `agent/internal/conn/backoff.go`：重连退避和随机抖动
- `agent/cmd/op-agent/`：生成实例 ID、接上 conn；`handler.go` 先占位
- main：`stable.proto` 的注释和 `protocol.md` 改为「不认识的消息一律忽略」（PR #4）
