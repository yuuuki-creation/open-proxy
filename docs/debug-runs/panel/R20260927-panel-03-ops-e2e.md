## 目的

1. 安装脚本和二进制下载：版本号、SHA-256 填对，下载认证正确
2. 真实安装：面板给的一行命令能在 root 下装好 systemd 服务，Agent 连上主控
3. 备份和恢复按 api.md 的流程工作
4. 自签证书：主控没有正式证书时用临时自签证书起 HTTPS

## 做法

1. `master/tests/e2e_ops.py`：主控 `--agent-dir` 指向放着 Agent 和测试签名的目录；建服务器后先测 `/api/agent/install.sh` 和 `/api/agent/binary/...`（无 Token、错 Token、错版本、正确）
2. 执行服务器详情里的安装命令，用 `OP_AGENT_SLICE=open-proxy.slice` 让服务进 slice；检查单元文件、配置文件权限、Agent 上线
3. 建套餐 → 下载备份 → 再建套餐 → 上传非法文件（应 400）→ 上传备份；等主控退出，检查退出码，重启后检查数据和旧库
4. 删除服务器（当时 Agent 还没有卸载功能，只检查接口）
5. 日志在 VPS 的 `/opt/open-proxy/runs/R20260927-panel-01/ops-1`
