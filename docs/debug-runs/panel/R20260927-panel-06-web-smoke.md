## 目的

在交给主会话看界面之前，先确认页面在真主控上不报错、接口字段对得上、主要操作能完成。

## 做法

1. 加锁；在 worktree `/opt/open-proxy/src/web-dev`（panel-web）里编译主控，目标目录单独放 `/opt/open-proxy/cache/target-web-dev`，产物复制到 `/opt/open-proxy/bin/op-master-panel-web-cb6400a`
2. 起主控：`op-master --data-dir <run>/data --no-https --http-listen 127.0.0.1:20480 --public-url http://127.0.0.1:20480`；前端 `pnpm build` 后 `OP_MASTER_URL=http://127.0.0.1:20480 pnpm exec vite preview --host 127.0.0.1 --port 20481`，都用 systemd-run 放在 open-proxy.slice
3. 开发电脑 `ssh -L 20481:127.0.0.1:20481` 后用内置浏览器操作；面板隐藏时截不了图，靠页面文字、无障碍树和 JS 读取检查
4. 测试凭据随机生成、用完即弃；结束后停掉 `op-R20260927-panel-web-01-*`、删 LOCK
