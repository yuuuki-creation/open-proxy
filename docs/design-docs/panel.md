## 页面

| 页面 | 主要内容 |
| --- | --- |
| 初始化 / 登录 | 首次启动时设置管理员账号、主控域名、Cloudflare API Token |
| 概览 | 流量概况：今天和本月的总流量、用户用量排行；最近 30 天每日总流量趋势图 |
| 服务器 | 列表：在线状态、Agent 版本、实时网速（10 秒刷新）、整机流量进度。详情：地址、端口范围、证书方式、月额度和重置日、生成安装命令、升级（含「全部升级」）、删除（Agent 自动卸载）、这台服务器上的节点、配置应用失败的项 |
| 节点 | 列表：协议、端口、所属服务器、落地出口、在哪些客户端里看不到。创建向导：选服务器 → 选协议 → 填参数（REALITY 目标选择和检测、Hysteria2 端口跳跃和混淆）→ 选出口。启用 / 停用；拖拽调整在订阅里的顺序 |
| 落地出口 | 登记第三方 SOCKS5；选一台服务器建成自建落地机 |
| 套餐 | 名称、流量额度、可用节点、绑定人数 |
| 用户 | 列表：套餐、已用 / 额度、到期时间、状态。操作：新建、续期、清零本周期用量、停用 / 启用、复制订阅链接、重置订阅链接和凭据、删除（流量记录一起删）、查看按节点和按天的流量明细 |
| 流量统计 | 按用户、节点、服务器分别看每日流量图表 |
| 订阅模板 | 当前模板；导入（粘贴、上传、远程地址和拉取周期）；兼容性报告；预览某个格式的输出 |
| 设置 | 主控域名和证书、Cloudflare Token、时区、管理员密码、数据备份与恢复 |

## 功能细节

### 超额后恢复

- 自动：到下一个重置日自动恢复
- 手动「清零本周期用量」：把这个人本周期的起点设为当前用量，重置日不变；历史流量和日账本不变
- 换成额度更大的套餐：下一轮超额检查发现用量低于新额度，自动恢复（超额检查本来的逻辑，不是单独的功能）

### 分享订阅

- 只提供「复制链接」

### 数据备份

- 设置页一键下载整个数据库的备份文件；上传备份文件恢复
- 备份时用 SQLite 的在线备份，不停服务

### 登录与访问

- 面板在域名根路径；订阅链接和面板用同一个域名
- 不做两步验证；安全靠强密码和登录失败限流（同一 IP 或账号连续失败多次后锁定一段时间）
- 会话：随机 Token 存数据库，Cookie 设 HttpOnly、Secure、SameSite；修改密码时让所有会话失效
